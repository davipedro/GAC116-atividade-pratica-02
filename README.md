# Portfólio pessoal — AC116 Programação Web

Portfólio com duas versões de interface, uma em Tailwind CSS e outra em Bootstrap. As duas compartilham conteúdo, foto, bandeiras e comportamento de tema.

## Estrutura

```text
__dev-portifolio/
├── index.html
├── assets/
│   ├── photo.png
│   ├── brasil.svg
│   ├── portugal.svg
│   ├── css/landing.css
│   └── js/theme.js
├── bootstrap/
│   ├── index.html
│   └── assets/css/style.css
└── tailwind/
    ├── index.html
    └── assets/css/style.css
```

Abra `index.html` no navegador para escolher uma versão. Tailwind CSS, Bootstrap e as fontes são carregados por CDN; é necessária conexão com a internet.

## GitHub Pages

1. Envie o conteúdo desta pasta para a raiz de um repositório público.
2. Em **Settings → Pages**, selecione a branch principal e `/(root)`.
3. Teste a página inicial e as duas versões publicadas.
