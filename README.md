# Portfólio pessoal — AC116 Programação Web

Portfólio com duas versões de interface, uma em Tailwind CSS e outra em Bootstrap. As duas compartilham conteúdo, foto, bandeiras e comportamento de tema.

Acesso em: https://davipedro.github.io/GAC116-atividade-pratica-02/

## Estrutura

```text
__dev-portifolio/
├── index.html
├── assets/
│   ├── photo.png
│   ├── brasil.svg
│   ├── portugal.svg
│   ├── css/landing.css
│   └── js/theme.js
├── bootstrap/
│   ├── index.html
│   └── assets/css/style.css
└── tailwind/
    ├── index.html
    └── assets/css/style.css
```
